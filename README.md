# RouteFoundry Technologies — GitHub defaults

This repository contains the public GitHub organization profile and default community-health files used across RouteFoundry Technologies repositories.

Repository-specific files take precedence where an individual project needs stricter or more specialized guidance.

## Included defaults

- organization profile in `profile/README.md`
- contribution guidance in `CONTRIBUTING.md`
- default pull request template in `PULL_REQUEST_TEMPLATE.md`
- security reporting guidance in `SECURITY.md`
- organization-level issue forms in `.github/ISSUE_TEMPLATE/`

For company information, visit https://routefoundry.co.za.
